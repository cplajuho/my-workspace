# 자료로 쓸 폴더를 한 줄에 하나씩 적으세요. (# 으로 시작하는 줄은 무시됩니다)
# 프로그램 옆의 '자료' 폴더는 따로 적지 않아도 항상 포함됩니다.
#
# ▶ 구글드라이브 폴더 쓰는 법
#   1) 'Google Drive for desktop' 설치 후 로그인 (https://www.google.com/drive/download/)
#   2) 탐색기에서 원하는 드라이브 폴더 → 우클릭 → '오프라인으로 사용 가능' 선택(권장)
#   3) 그 폴더 경로를 아래에 적기. 탐색기 주소창에서 복사하면 됩니다.
#
# 예시 (Windows) — 앞의 # 을 지우면 적용됩니다
# G:\내 드라이브\닥터길_직괴조사(2610)\참고자료
# G:\내 드라이브\개별노동법실무(2025)
#
# 예시 (Mac)
# ~/Library/CloudStorage/GoogleDrive-내계정@gmail.com/내 드라이브/닥터길_직괴조사(2610)/참고자료
