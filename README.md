# ⚖️ 노동법지식in

`자료/` 폴더에 넣은 노동법 자료(실무서, 행정해석, 판례집 등)를 근거로
**자문 노무사**처럼 답변해 주는 상담 프로그램입니다.

- 질문하면 Claude가 자료를 직접 검색하고(쟁점별·동의어 반복 검색), 필요한 쪽을 원문으로 확인한 뒤 답합니다.
- 답변은 자문 의견서 형식: **결론 요약 → 쟁점 → 검토 의견 → 실무 권고 → 추가 확인 사항**
- 근거에는 `[자료명 p.쪽]` 출처가 붙고, 자료 밖 일반론은 따로 표시됩니다.
- 이어서 질문하면 앞 대화를 기억합니다(`새 상담`으로 초기화).

## 1. 설치 (처음 한 번)

```bash
pip install -r requirements.txt
```

Anthropic API 키가 필요합니다 (https://console.anthropic.com 에서 발급).

```bash
# Windows (PowerShell)
setx ANTHROPIC_API_KEY "sk-ant-..."     # 설정 후 창을 새로 여세요
# Mac / Linux
export ANTHROPIC_API_KEY="sk-ant-..."
```

## 2. 자료 넣기

`자료/` 폴더에 파일을 넣으세요. 하위 폴더도 됩니다.

| 형식 | 지원 |
|---|---|
| PDF (텍스트 PDF) | ✅ 쪽 번호까지 인용 |
| DOCX, HWPX, TXT, MD | ✅ |
| HWP (구 한글) | ❌ → 한글에서 PDF 또는 HWPX로 저장 |
| 스캔본 PDF (이미지) | ❌ → OCR 처리 후 넣기 |

**자료는 계속 추가/수정해도 됩니다.** 다음 실행(또는 `/재색인`, 웹 화면의 "자료 다시 읽기") 때
바뀐 파일만 다시 읽습니다. 수백 MB짜리 PDF는 처음 한 번 읽는 데 몇 분 걸리고, 이후엔 `.index/` 캐시를 씁니다.

### 구글드라이브 자료도 함께 쓰기

1. **Google Drive for desktop** 설치 후 로그인 → PC에 `G:\내 드라이브` 같은 드라이브가 생깁니다.
2. 쓸 폴더(예: `닥터길_직괴조사(2610)\참고자료`)를 우클릭 → **오프라인으로 사용 가능** (권장, 큰 PDF 읽기가 빨라짐)
3. `자료폴더.txt`에 그 폴더 경로를 한 줄에 하나씩 적기 (파일 안에 예시가 있습니다)

드라이브에 파일을 추가하면 PC에 자동 동기화되고, 다음 실행 때 반영됩니다.
구글 문서(.gdoc) 형식은 읽을 수 없으니 PDF/DOCX로 다운로드해 넣어 주세요.

## 3. 실행

**웹 화면 (추천)**

```bash
streamlit run app.py
```

**터미널**

```bash
python 상담.py
```

터미널 명령어: `/새상담` `/자료` `/재색인` `/종료`

## 구조

```
상담.py              터미널 상담
app.py               웹 상담 화면 (Streamlit)
labor_kb/
  loader.py          PDF·DOCX·HWPX·TXT 텍스트 추출
  index.py           자료 색인(캐시) + 한글 검색(BM25)
  advisor.py         노무사 페르소나 프롬프트 + Claude 호출
  config.py          자료 폴더 설정 읽기
자료/                여기에 자료를 넣습니다 (git에는 올라가지 않음)
자료폴더.txt         추가로 읽을 폴더(구글드라이브 등) 목록
```

노무사 말투·답변 형식을 바꾸고 싶으면 `labor_kb/advisor.py`의 `SYSTEM_PROMPT`를 고치면 됩니다.
비용을 줄이고 싶으면 같은 파일의 `EFFORT`를 `"medium"`으로 낮추세요.
