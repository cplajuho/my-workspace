# ⚖️ 노동법지식in

`자료/` 폴더에 넣은 노동법 자료(실무서, 행정해석, 판례집 등)를 근거로
**자문 노무사**처럼 답변해 주는 상담 프로그램입니다.

- 질문하면 Claude가 자료를 직접 검색하고(쟁점별·동의어 반복 검색), 필요한 쪽을 원문으로 확인한 뒤 답합니다.
- 답변은 자문 의견서 형식: **결론 요약 → 쟁점 → 검토 의견 → 실무 권고 → 추가 확인 사항**
- 근거에는 `[자료명 p.쪽]` 출처가 붙고, 자료 밖 일반론은 따로 표시됩니다.
- 이어서 질문하면 앞 대화를 기억합니다(`새 상담`으로 초기화).

## 0. 새 PC에서 시작하기 (Windows)

1. 이 저장소를 내려받아 압축을 풉니다 (GitHub → **Code → Download ZIP**).
2. **실행.bat** 더블클릭 — 처음 한 번은 파이썬·필요한 프로그램을 자동 설치하고 API 키를 물어봅니다.
3. 브라우저에 상담 화면이 열립니다. 다음부터는 **실행.bat**만 누르면 됩니다.

구글드라이브 자료를 쓰려면 `자료폴더.예시.txt`를 `자료폴더.txt`로 복사해 폴더를 적어 주세요.
`자료폴더.txt`는 그 PC에만 저장되고 GitHub에는 올라가지 않습니다.

## 1. 설치 (직접 하는 경우)

```bash
pip install -r requirements.txt
```

Anthropic API 키가 필요합니다 (https://console.anthropic.com 에서 발급).

```bash
# Windows (PowerShell)
setx ANTHROPIC_API_KEY "sk-ant-..."     # 설정 후 창을 새로 여세요
# Mac / Linux
export ANTHROPIC_API_KEY="sk-ant-..."
```

## 2. 자료 넣기

`자료/` 폴더에 파일을 넣으세요. 하위 폴더도 됩니다.

| 형식 | 지원 |
|---|---|
| PDF (텍스트 PDF) | ✅ 쪽 번호까지 인용 |
| DOCX, TXT, MD | ✅ |
| HWP, HWPX (한글) | ✅ (배포용·암호 문서는 ❌ → PDF로 저장) |
| 스캔본 PDF (이미지) | ❌ → OCR 처리 후 넣기 |

**자료는 계속 추가/수정해도 됩니다.** 다음 실행(또는 `/재색인`, 웹 화면의 "자료 다시 읽기") 때
바뀐 파일만 다시 읽습니다. 수백 MB짜리 PDF는 처음 한 번 읽는 데 몇 분 걸리고, 이후엔 `.index/` 캐시를 씁니다.

### 구글드라이브 자료도 함께 쓰기

1. **Google Drive for desktop** 설치 후 로그인 → PC에 `G:\내 드라이브` 같은 드라이브가 생깁니다.
2. 쓸 폴더(예: `참고자료`)를 우클릭 → **오프라인으로 사용 가능** (권장, 큰 PDF 읽기가 빨라짐)
3. `자료폴더.txt`에 `구글드라이브/폴더/경로` 형식으로 적기 — 드라이브 글자(G: 등)는 프로그램이 알아서 찾습니다 (`자료폴더.예시.txt` 참고)

드라이브에 파일을 추가하면 PC에 자동 동기화되고, 다음 실행 때 반영됩니다.
구글 문서(.gdoc) 형식은 읽을 수 없으니 PDF/DOCX로 다운로드해 넣어 주세요.

### 특정 자료 빼기

`자료폴더.txt`에 `제외: 글자` 줄을 넣으면 경로에 그 글자가 들어간 파일·폴더는 읽지 않습니다.
기본으로 다음은 빼 두었습니다.
- 개별노동법실무 2025년판 (`2025버전`, `개별노동법실무(2025)`)
- 사건 폴더·서류: 이름이 `260909-`처럼 날짜 6자리+하이픈으로 시작하는 것 (`/^\d{6}-/`)

`/ /`로 감싼 값은 정규식으로, 폴더·파일 이름 하나하나에 적용됩니다.
사건 서류가 섞이지 않도록 **참고자료 폴더만 연결하는 것**을 권장합니다.

## 3. 실행

**웹 화면 (추천)**

```bash
streamlit run app.py
```

**터미널**

```bash
python 상담.py
```

터미널 명령어: `/새상담` `/자료` `/재색인` `/종료`

## 구조

```
설치.bat / 실행.bat  Windows 더블클릭 설치·실행
상담.py              터미널 상담
app.py               웹 상담 화면 (Streamlit)
labor_kb/
  loader.py          PDF·DOCX·HWP·HWPX·TXT 텍스트 추출
  index.py           자료 색인(캐시) + 한글 검색(BM25)
  advisor.py         노무사 페르소나 프롬프트 + Claude 호출
  config.py          자료 폴더 설정 읽기
자료/                여기에 자료를 넣습니다 (git에는 올라가지 않음)
자료폴더.예시.txt    자료폴더.txt(이 PC 전용 설정) 작성 예시
```

노무사 말투·답변 형식을 바꾸고 싶으면 `labor_kb/advisor.py`의 `SYSTEM_PROMPT`를 고치면 됩니다.
비용을 줄이고 싶으면 같은 파일의 `EFFORT`를 `"medium"`으로 낮추세요.
